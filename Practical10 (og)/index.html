Core Practical 10 Module

Secure Login, Logout & RBAC Portal

Enterprise-grade session authentication architecture:

  • Session Hardening: HttpOnly, SameSite=Lax, use_strict_mode=1.
  • Session Fixation Defense: session_regenerate_id(true) on privilege changes.
  • Role-Based Access Control: Strict redirection for ADMIN, FACULTY, and STUDENT.
  • Inactivity Timeout: Automatic termination after idle window with visual countdown.
  • Intermediate Extension: Relational last_login timestamp tracker.
  • Advanced Extension: Cryptographic split-token Remember-Me cookie (sha256 DB hash).
